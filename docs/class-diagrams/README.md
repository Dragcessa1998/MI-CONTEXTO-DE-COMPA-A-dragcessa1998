# Class diagrams

Deliverables for the object-modeling projects in the 4Geeks AI Engineering program.

## Digital wallet

- [`digital-wallet-class-diagram.png`](./digital-wallet-class-diagram.png) — required PNG deliverable.
- [`digital-wallet-class-diagram.svg`](./digital-wallet-class-diagram.svg) — editable vector source.

The model covers `User`, `Wallet`, `Currency`, and `Transaction`, including typed properties and explicit cardinalities for ownership, denomination, source/destination wallets, and settlement currency.

## Music playlist player

- [`music-playlist-class-diagram.png`](./music-playlist-class-diagram.png) — required PNG deliverable.
- [`music-playlist-class-diagram.svg`](./music-playlist-class-diagram.svg) — editable vector source.

The model covers `User`, `Playlist`, `PlaylistSong`, `Song`, `Album`, and `Artist`. `PlaylistSong` resolves the many-to-many relationship between playlists and songs, while the remaining relationships show their explicit cardinalities.
